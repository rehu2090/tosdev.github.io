Kebijakan Privasi TOKKO POS

Berlaku untuk aplikasi TOKKO POS yang dikembangkan oleh TOS Developer (Teknologi Otomasi Studio).

Terakhir diperbarui: 21 September 2026

1. Data yang Disimpan Aplikasi

TOKKO POS menyimpan data usaha Anda (produk, transaksi penjualan/pembelian, stok, laporan keuangan, dan data akun pengguna di dalam toko Anda) secara lokal di perangkat tempat aplikasi terpasang. Pada mode Server/Client, data ini disinkronkan antar perangkat hanya di dalam jaringan lokal (WiFi/LAN) toko Anda sendiri.

TOS Developer tidak memiliki akses ke data usaha yang tersimpan di aplikasi Anda, dan data tersebut tidak dikirim ke server milik TOS Developer atau pihak ketiga mana pun.

2. Pengecekan Pembaruan Aplikasi

Aplikasi dapat memeriksa apakah ada versi terbaru yang tersedia. Proses ini hanya mengambil (bukan mengirim) informasi versi terbaru dari sumber publik yang disediakan TOS Developer, dan tidak menyertakan data pribadi atau data usaha Anda apa pun.

3. Aktivasi Lisensi

Aplikasi menghasilkan sebuah ID Perangkat (device fingerprint) yang dipakai untuk mengaktifkan lisensi. ID ini tidak dikirim otomatis oleh aplikasi ke mana pun — Anda sendiri yang memilih untuk membagikannya ke TOS Developer (misalnya lewat email/telepon) saat meminta kode aktivasi.

4. Izin Perangkat

Aplikasi dapat meminta izin berikut, sesuai kebutuhan fiturnya:

  • Bluetooth — untuk terhubung ke printer struk thermal.
  • Sensor sidik jari / biometrik — untuk fitur kunci PIN/keamanan aplikasi, jika diaktifkan.

Izin ini tidak dipakai untuk mengumpulkan atau mengirim data ke luar perangkat Anda.

5. Iklan & Pelacakan

TOKKO POS tidak menampilkan iklan dan tidak menggunakan layanan analitik/pelacakan pihak ketiga apa pun.

6. Keamanan Data

Karena data tersimpan lokal di perangkat Anda, keamanan data juga bergantung pada keamanan perangkat itu sendiri (mis. kunci layar, antivirus, akses fisik ke perangkat). Kami menyarankan penggunaan fitur kunci PIN aplikasi dan menjaga perangkat kasir Anda tetap aman.

7. Perubahan Kebijakan Ini

Kebijakan privasi ini dapat diperbarui sewaktu-waktu. Perubahan akan ditampilkan di halaman ini dengan tanggal pembaruan terbaru.

8. Hubungi Kami

Ada pertanyaan soal kebijakan privasi ini? Hubungi kami di admintosdev@gmail.com atau lihat halaman Kontak.
